# Proposal: 重构训练模块为单题模式

## 问题背景

当前训练页面（`/training/session`）采用"同时展示5道题"的交互设计：
- 进入页面后同时生成并显示5个维度的题目
- 用户需要点击某道题进入答题区
- 这种设计导致页面信息密度过高，用户注意力分散

## 目标

将训练模块重构为**单题模式**：
1. 每次只显示一道题，做完一道切下一道
2. 每天5题，对应5个维度（战略思维、系统设计能力、数据决策能力、用户洞察与需求管理、商业思维）
3. 支持做完一轮（5题）后继续下一轮，也可以随时结束
4. 每道题可重新出题
5. AI 分析分为"诊断"和"建议"两大块
6. AI 分析启用深度思考模式

## 范围

### 包含
- `src/app/(app)/training/session/page.tsx` 重写为单题交互
- `src/app/api/train/route.ts` 修改分析 prompt，明确分为诊断和建议
- 进度指示、维度标识、重新出题、结束训练等交互

### 不包含
- 数据库 schema 变更（`training_sessions`、`training_records` 表已满足需求）
- 训练统计 API 变更（`/api/training/stats` 保持不变）
- 诊断、特训等其他模块

## 非目标

- 不改变题目的生成逻辑（仍由 DeepSeek v4 Flash 生成）
- 不改变答题记录的存储格式
- 不引入新的数据库表
