# 升云阶工作型界面重设计

## 目标

把现有页面从“概念解释 + 卡片陈列”改成安静、专业、可反复使用的高级 PM 工作台。重设计覆盖全局导航、工作台、训练首页、训练复盘和面试冲刺；保留现有 API、数据持久化和成长闭环，不增加数据库表或依赖。

## 研究依据

- Product Alliance：课程上下文固定在左侧，主区域只突出当前内容和下一步动作；进度持续可见，但不与主任务争抢注意力。
- BetterUp：登录后的首屏围绕“今天最值得做什么”，次要内容被压缩成简短列表；教练判断短而明确。
- Reforge：层级由字号、留白和少量强调色建立，导航与内容边界稳定，不依赖大量装饰。
- Asana / Linear 类工作台：高频信息使用列表、行分隔和稳定列宽；状态靠小图标和颜色表达，而不是每项一个卡片。

这些参考只用于提炼结构规则，不复制品牌、文案或视觉外观。

## 核心原则

1. 每页只有一个视觉上最强的动作。
2. 页面标题控制在 24-28px，正文控制在 14-15px；禁止运营式巨型 Hero。
3. 解释性文案只保留完成任务所需的一句，能由状态、数字或控件表达的内容不再写成段落。
4. 主信息用列表、表格、步骤和分隔线组织；卡片只用于独立对象、编辑器和需要明确边界的工具。
5. 全站采用统一浅色表面，不再插入页面级黑色面板。
6. 颜色只承担动作和状态：蓝色为主动作，绿色为完成，琥珀为风险，红色为错误。
7. 桌面端使用固定左侧导航，移动端使用紧凑顶部栏和抽屉导航。

## 视觉系统

- 页面背景：`#F6F7F5`
- 主表面：`#FFFFFF`
- 次表面：`#F0F2EF`
- 主文字：`#171A1F`
- 次文字：`#59616D`
- 分隔线：`#DDE2E6`
- 主色：`#3157D5`
- 完成：`#24835B`
- 风险：`#C88624`
- 错误：`#C74D4D`
- 圆角：工具面板 8px，行内控件 6px；不使用 16px 以上大圆角。
- 阴影：仅导航浮层和弹出菜单使用轻阴影，页面区块依靠分隔线和背景层级。

## 全局导航

桌面端左侧导航宽 208px，包含“今日、训练复盘、面试证据、能力画像”。品牌和当前页面固定可见，设置与用户入口位于底部。移动端保留顶部品牌栏，通过菜单展开相同入口。

## 工作台

工作台采用“聚焦队列”结构：

- 顶部只展示当前主线和目标岗位，目标简报通过内联编辑展开。
- 左侧主区域展开今日优先任务，展示任务标题、能力维度、状态和三步证据流；只有一个主按钮。
- 同一区域下方列出后续三项任务，点击后在原位展开，不跳到第二套导航。
- 右侧仅展示面试就绪、可讲项目、追问风险、终版表达和最弱能力。
- 底部使用“最近证据”表格，不再使用资产卡片墙。
- 画像账本、训练处方和复盘数据移到首屏之后，以连续工作区呈现。

## 训练首页

训练首页从“作战概念集合”改为“训练队列”：

- 第一行直接展示待二次修正的回答；存在待修正时，开新题降级为次级动作。
- 中间以列表合并待修正和已可用资产，状态为“待修正、可入账、已沉淀”。
- 目标岗位和当前处方放入右侧简报，不重复解释推荐逻辑。
- 训练节奏、维度分布和归档记录放在页面下部的紧凑数据区。

## 训练复盘

复盘页采用“原答 / 修正版 / 入账”三阶段工作流：

- 顶部只显示题目摘要、分数和当前阶段。
- 原答与 AI 反馈并排但不使用黑色容器。
- 修正版编辑器是页面主工具，保存后在同屏开放表达卡或思维升级卡入账。
- 面试表达资产、思维升级资产和迁移验证使用分组行，不重复出现“处理台、动作台、工作台”等概念名称。

## 面试冲刺

面试冲刺改为“证据库队列”：

- 顶部只显示目标岗位、就绪度和下一步动作。
- 四个资产数字合并为一行状态摘要。
- 主区域使用证据缺口列表，按优先级进入项目故事、模拟追问或表达打包。
- 项目故事库、模拟面试和报告作为右侧工具入口，不再各自占据大卡片。

## 交互状态

- 所有主按钮提供 hover、pressed、focus-visible 和 disabled 状态。
- 数据加载使用与最终布局一致的骨架屏。
- 保存失败在控件附近显示内联错误，不使用浏览器弹窗。
- 空状态只给出一个下一步，不展示功能说明。

## 数据与后端

本次不改变 Supabase schema、API 契约或写入链路。Dashboard、训练、复盘和面试冲刺继续从现有 API 读取，并复用既有 `growth_snapshots`、`training_records`、`bootcamp_sessions` 和 `bootcamp_interviews` 数据。

## 验收标准

- 四个核心页面不存在页面级黑色面板和巨型 Hero。
- 首屏每页只有一个填充色主按钮。
- 页面上的解释性段落显著减少，主要结构由列表、表格、步骤和状态组成。
- 桌面 1440x1024 与移动 390x844 无文字溢出、遮挡或横向滚动。
- 现有数据读取、保存、入账、复制、跳转和处方选择行为保持可用。
- TypeScript、ESLint、Next build、相关测试和 `./init.sh` 全部通过。
